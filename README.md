# BAC2027

مشروع لإنتاج محتوى تعليمي منهجي لمساعدة طلبة البكالوريا الجزائرية 2027، بدءاً بمادة الرياضيات.

## فلسفة المشروع
لا يُبنى المحتوى على التوليد الحر بالذكاء الاصطناعي، بل على سلسلة مرجعية قابلة للتتبع:
1. الوثائق الرسمية.
2. التدرجات السنوية المعتمدة.
3. الكتاب المدرسي.
4. مواضيع البكالوريا الوطنية السابقة.
5. خريطة كفاءات ومهارات.
6. تصميم المحتوى التعليمي.
7. تحقق رياضي وبيداغوجي قبل النشر.

## مساحتا العمل
- Google Drive: الأصول المرجعية والملفات التعليمية ومواد الإنتاج.
- GitHub: التوثيق، الخرائط، البيانات المنظمة، القرارات، وسجل التغييرات.

## النطاق الأول
- المستوى: الثالثة ثانوي.
- الشعبة التجريبية الأولى: علوم تجريبية.
- المادة: الرياضيات.
- الهدف: بكالوريا 2027.

## مبدأ التتبع
كل مفهوم أو مهارة أو تمرين أو فيديو ينبغي أن يكون قابلاً للربط بمصدره، وبموضعه في البرنامج، وبالأسئلة الفعلية ذات الصلة في البكالوريا السابقة.
